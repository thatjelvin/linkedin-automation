## Commands Reference

### Setup & Validation
```bash
# Clone repository
git clone https://github.com/thatjelvin/linkedin-automation.git
cd linkedin-automation

# Setup environment
cp .env.example .env
# Edit .env with your credentials

# Validate setup
npm install dotenv  # optional
npm run validate

# Or directly
node validate-setup.js
```

### Import to n8n
```bash
# In n8n interface:
1. Click "+" → "Import from File"
2. Select linkedin-ai-ml-learning-workflow.json
3. Configure credentials
4. Set environment variables
5. Test and activate
```

### Testing
```bash
# Validate JSON
python3 -m json.tool linkedin-ai-ml-learning-workflow.json

# Check file structure
ls -lh

# Verify environment variables
cat .env.example
```
